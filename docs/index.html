Everything an AI assistant needs to quote you

AI assistants search, fetch a handful of pages and quote the ones they can read fastest. They don't run JavaScript, they trust structured data to know who is speaking, and they lift the plain sentence that answers the question. geo-kit covers each step.

Quick start for Next.js

Install from GitHub, then add three files. Each one ships in the raw HTML or as a static route, so AI crawlers read it on the first request.

1JSON-LD on every page

Build a linked @graph with typed helpers. <JsonLd> is a server component and escapes its output safely.

// app/layout.tsx
import { graph, organization, webSite, ref, idFor } from "geo-kit";
import { JsonLd } from "geo-kit/react";

const url = "https://example.com";

<JsonLd data={graph(
  organization({ name: "Example", url, logo: `${url}/logo.png` }),
  webSite({ name: "Example", url, publisher: ref(idFor(url, "organization")) }),
)} />

2robots.ts that welcomes AI

Every AI search and live-fetch crawler, named and allowed. Pass allowTraining: false to stay quotable while opting out of training.

// app/robots.ts
import { aiRobots } from "geo-kit";

export default function robots() {
  return aiRobots({
    sitemap: "https://example.com/sitemap.xml",
    disallow: ["/api/"],
  });
}

3llms.txt as a static route

One config feeds llms.txt; add Markdown content to links and serve generateLlmsFullTxt() for the full-text version.

// app/llms.txt/route.ts
import { generateLlmsTxt, textResponse } from "geo-kit";
import { llms } from "@/lib/llms";

export const dynamic = "force-static";
export function GET() {
  return textResponse(generateLlmsTxt(llms));
}

Score any page for AI search

The audit fetches your page, its robots.txt and llms.txt, then fetches the page again as OAI-SearchBot, ClaudeBot and PerplexityBot to catch CDN and firewall blocks. You get a score out of 100 and a plain fix for every gap.

Add --min-score 80 to fail a CI run when a deploy makes a page harder to quote, or --json to feed the result into your own dashboards.

# after npm install github:behoss/geo-kit
npx geo-kit audit https://your-site.com
npx geo-kit audit https://your-site.com --min-score 80
npx geo-kit robots --no-training --sitemap https://your-site.com/sitemap.xml

The GEO checklist

What gets a page quoted by ChatGPT, Gemini, Perplexity and Claude. The audit checks every line.

Structured data

  • JSON-LD in the server HTML, with @context set to schema.org
  • Organization or Person with sameAs links that prove who you are
  • A page node and a BreadcrumbList on every page
  • FAQPage that mirrors the visible questions word for word

Head and raw HTML

  • A title that leads with the words people search for
  • One absolute, self-referencing canonical
  • One H1, and the full text in the HTML the server sends
  • H2 sections with lists and tables assistants can lift whole

AI crawler access

  • robots.txt names and allows OAI-SearchBot, ChatGPT-User, Claude-SearchBot, PerplexityBot, Googlebot and Bingbot
  • Your CDN serves those user agents a 200, not a challenge page
  • /llms.txt with a title, a summary and links to key pages

Quotability

  • The first sentence under the H1 answers the question in under 45 words
  • Prices, timelines, counts and dates near the top
  • Headings phrased as the questions people ask
  • A visible, machine-readable updated date

Questions developers ask

What is GEO?
GEO (generative engine optimisation) is the work of making a page easy for AI assistants such as ChatGPT, Gemini, Perplexity and Claude to find, read and quote in their answers.
Does blocking GPTBot stop ChatGPT quoting my site?
No. GPTBot collects pages for model training. ChatGPT search uses OAI-SearchBot and live fetches use ChatGPT-User, so you can block GPTBot and still be quoted, as long as those two are allowed.
Do AI crawlers run JavaScript?
Most do not. They read the HTML your server sends, so content that only appears after client-side rendering is invisible to them. Render it on the server with Next.js server components, static generation or SSR.
What is llms.txt?
llms.txt is a Markdown file at the root of a site with a title, a one-paragraph summary and links to its key pages, so AI assistants can understand the site in one request. geo-kit generates it, and llms-full.txt, from one config.
